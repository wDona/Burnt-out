# Security Policy

## Versiones
Ninguna version es segura actualmente

## Reporta una vulnerabilidad
Si la vulnerabilidad solo te permite acceder a informacion de la aplicacion, crea una issue con la tag de vulnerabilidad, si te permite acceder a informacion 
personal de los usuarios como fotos, aplicaciones u otros datos no relacionados con la aplicacion, envia un correo a me@wdona.dev con toda la informacion posible
